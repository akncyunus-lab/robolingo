# 🤖 RoboLingo

Çocuklar için başlangıç seviyesinde, konuşma odaklı İngilizce öğrenme uygulaması.

## İlk sürüm
- Çocuk dostu ana ekran
- Robo karakteri
- Dersler / konuşma / oyun / ilerleme bölümleri için temel navigasyon
- Popüler ders kartları
- Yıldız ve günlük seri göstergeleri
- Android APK için GitHub Actions

## Android
GitHub'da `Actions > RoboLingo Android APK > Run workflow` ile APK oluşturulabilir.
